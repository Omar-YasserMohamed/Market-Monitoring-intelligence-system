1. Modern Cloud-Native Standard (Object Storage vs. Block Storage)
The Industry Shift: In modern data engineering, the industry has largely moved away from on-premise Hadoop clusters toward cloud object storage like Amazon S3, Google Cloud Storage (GCS), or Azure Blob / ADLS Gen2.
Why MinIO? MinIO is an S3-compatible object store. Writing Spark jobs, Airflow tasks, or ingestion pipelines against MinIO uses the exact same S3 APIs (s3a://...). If tomorrow you decide to deploy this project to AWS, Azure, or GCP, you change zero lines of pipeline code—only the connection URL and credentials. HDFS does not give you this cloud-native portability.
